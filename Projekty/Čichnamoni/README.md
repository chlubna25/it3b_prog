# Čichnamoni

Jednoduchá konzolová hra vytvořená v jazyce C#.

## O projektu

Čichnamoni jsou malá kapesní čichnovská monstra, která mezi sebou bojují v soubojích.

Hráč si vytvoří trenéra, vybere svého Čichnamona a následně bojuje proti protivníkovi.

Projekt byl vytvořen jako školní práce pro procvičení objektově orientovaného programování (OOP).

## Použité třídy

### Utok

Reprezentuje jeden útok.

Obsahuje:
- název útoku
- poškození útoku

### Cichnamon

Reprezentuje jedno monstrum.

Obsahuje:
- jméno
- zdraví
- základní útok
- speciální útok

### Trener

Reprezentuje hráče.

Obsahuje:
- jméno
- level
- seznam vlastněných Čichnamonů
- vybraného Čichnamona

## Dostupní Čichnamoni

- Základní útok: Malta
- Speciální útok: BrnoTU

## Jak hrát

1. Spusť program.
2. Zadej jméno trenéra.
3. Vyber svého Čichnamona.
4. V souboji vybírej akce:
   - základní útok
   - speciální útok
   - léčení
5. Poraz protivníka a získej level.

# Projekty

Tato složka obsahuje větší projekty vytvořené v rámci výuky programování i vlastní projekty vytvářené mimo školu.

## Obsah složky

### Čichnamoni

Školní projekt vytvořený pro procvičení objektově orientovaného programování (OOP).

Projekt obsahuje:

- práci s třídami a objekty,
- propojení více tříd,
- práci se seznamy,
- jednoduchý soubojový systém,
- správu postav a útoků.

### Farken's World

Vlastní projekt inspirovaný survival hrou Rust.

Projekt slouží především k procvičení programování, návrhu herních mechanik a postupnému rozšiřování větší aplikace.

Obsahuje například:

- inventář,
- crafting,
- survival systém,
- správu předmětů,
- herní mapu,
- další plánované herní mechaniky.

## Cíl složky

Cílem této složky je uchovávat větší projekty, sledovat jejich vývoj a dokumentovat získané zkušenosti při programování.

# TESTY

Tato složka obsahuje řešení testů, cvičení a procvičovacích úloh z předmětu Programování.

## Účel složky

Složka slouží jako archiv řešení jednotlivých testů a zároveň jako studijní materiál pro opakování před dalšími testy.

## Obsah

V jednotlivých podsložkách jsou uložena zadání a řešení zaměřená například na:

* pole
* stringy
* listy
* funkce
* objektově orientované programování (OOP)
* práci se třídami a objekty

## Poznámka

Řešení odpovídají znalostem získaným během výuky a používají postupy probírané v hodinách programování.

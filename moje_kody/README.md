# Moje kódy

Tato složka obsahuje programy, cvičení a ukázkové příklady vytvořené během výuky programování.

## Obsah složky

### C

Programy vytvořené v jazyce C.

Obsahují například:

- práci s proměnnými,
- podmínky,
- cykly,
- funkce,
- pole,
- řetězce,
- jednoduché algoritmy.

### C#

Programy vytvořené v jazyce C#.

Obsahují například:

- práci s poli,
- stringy,
- listy,
- funkcemi,
- objektově orientovaným programováním (OOP),
- třídami a objekty.

### TESTY

Složka obsahující řešení testů a procvičovacích úloh.

Slouží jako archiv odevzdaných prací a zároveň jako studijní materiál pro opakování.

## Účel

Cílem této složky je uchovávat řešení úloh z výuky a sledovat postupné zlepšování programátorských dovedností.
